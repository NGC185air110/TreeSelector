# TreeSelector
Android  选择器
一个自用的选择器用于自己的项目
使用下面的方法导入
全局添加
`dependencyResolutionManagement {
		repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
		repositories {
			mavenCentral()
			maven { url = uri("https://jitpack.io") }
		}
	}`
和具体项目
`dependencies {
	        implementation("com.github.NGC185air110:TreeSelector:1.6.1")
	}`
